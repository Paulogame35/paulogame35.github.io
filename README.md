# NEXORA Tools v2

Versão ampliada do NEXORA Tools, sem Replit e sem assinatura.

## Incluído
- Link do WhatsApp
- QR Code com download
- Porcentagem
- Regra de 3
- Desconto/acréscimo
- Calculadora de idade
- Estimativa educativa de salário
- Contador de texto
- Conversor de maiúsculas/minúsculas
- Gerador de slug
- Comprimir imagem
- Redimensionar imagem
- Converter imagem JPG/PNG/WebP
- Imagem → PDF
- Gerador de currículo
- Recibo
- Declaração
- Orçamento

## Como abrir
Extraia o ZIP e abra `index.html` no navegador.

## Publicação
O projeto é estático e pode ser publicado gratuitamente em serviços que hospedam sites estáticos.

## Observação
As bibliotecas QR Code e jsPDF são carregadas por CDN quando houver internet. As ferramentas de imagem, texto e cálculos funcionam no navegador.
